## About the releases in this repository

The releases previously published here were early experimental versions of AirPort_RTW88.

They contain stability and connectivity issues that have since been addressed and **do not represent the current state of the driver**.

For this reason, these releases are deprecated and should no longer be used for new installations.

> **Please migrate to Realtek AirPort Family for the current version of AirPort_RTW88.**
